# Galería de Inicio

Agrega aquí las imágenes o videos que quieras mostrar en el carrusel de la página de Inicio.

Formatos admitidos: `png`, `jpg`, `jpeg`, `webp`, `gif`, `mp4` y `webm`.

Para publicar un archivo en el carrusel, impórtalo y agrégalo a `MEDIA_ITEMS` en
`src/components/HomeMediaCarousel.jsx`. El orden de esa lista es el orden del carrusel.

Reinicia `npm run dev` después de agregar archivos.
